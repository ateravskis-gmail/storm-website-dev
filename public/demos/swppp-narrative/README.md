# SWPPP narrative writing demo

16-second silent loop, 1600 × 900 at 30 fps. Shows the project-location description being entered, the photo dialog opening, the caption “View looking east at the project site.” being typed, and the captioned photo attached beneath the narrative.

MP4 and WebM exports are ready to embed. GIF is a looping preview; poster.png is the still fallback. index.html has play/pause and respects reduced-motion preferences.

This demo is saved locally and has not been added to a website tab. The photo file-selection step is condensed. The caption completes the truncated text visible in the final reference screenshot.

Regenerate with scripts/render-swppp-narrative.py and a directory with after.png normalized to 2048 × 1165 and modal.png normalized to 1897 × 1312. Requires Pillow and imageio-ffmpeg.
